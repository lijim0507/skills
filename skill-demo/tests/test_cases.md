# 测试用例

## 用例 1：正常摘要

- 输入：`分析 report.pdf`（存在的 PDF 文件）
- 期望：脚本输出总页数与正文文本；摘要包含 `# 文档摘要：` 与 `## 核心内容`

## 用例 2：文件不存在

- 输入：`分析 not-exist.pdf`
- 期望：脚本以非零退出码结束，提示 `错误：文件不存在`

## 用例 3：扩展名不正确

- 输入：`分析 notes.txt`
- 期望：脚本以非零退出码结束，提示 `错误：文件类型不支持`

## 用例 4：超大文件

- 输入：一个超过 100 MB 的 PDF
- 期望：脚本先输出 `警告：文件较大`，再正常执行提取
