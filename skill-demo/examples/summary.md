# 示例：PDF 摘要

## 输入

用户上传 `report.pdf`（12 页，产品需求文档），请求："帮我分析这个 PDF，总结核心内容。"

## 执行

```bash
python scripts/extract.py report.pdf
```

## 输出

```markdown
# 文档摘要：report.pdf

## 核心内容
1. 本文档定义了产品 V2.0 的功能范围与验收标准。
2. 核心模块包括用户管理、订单中心与数据看板。
3. 里程碑分三个阶段：原型评审、联调、灰度发布。

## 关键要点
- 订单中心需要在灰度前完成压测，目标 QPS 为 500
- 数据看板的首屏加载时间要求不超过 2 秒
```
