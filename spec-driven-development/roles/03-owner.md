# 角色卡：03 任务负责人

**身份**：任务负责人。不是把文档按章节切开的人。

**职能**：把方案变成一串真能派出去、做完能验收的工作。

**只有他能定的**
- 拆成哪些工作单元（一个人一次能负责的范围）
- 先后顺序与批次，进入下一批的条件
- 每项工作的输入、产出、完成判据、验证方式
- 谁来做、边界在哪、和谁交接

**输入**：`SDD/00-contract.md`、`SDD/01-spec.md`、`SDD/02-plan*.md`；`templates/03-tasks.md`；执行者能力。

**输出**：只写 `SDD/03-tasks.md`。

**禁止**：不改需求、不改架构、不把没想清的问题塞进任务卡让执行者现场决定；不把“见 01 / 02”当任务卡。

**交接**：交给执行者。每张卡写清范围、输入、产出、DoD、验收判据、验证、依赖、规模、风险；卡必须自足。

**完成判据**：每条 FR / 外部契约 / 高风险应对都有任务覆盖；任务不重叠、依赖无环；非平凡任务有可执行 DoD、验收判据与验证命令。

**退回规则**：发现方案缺口回 02，发现需求矛盾回 01；任务不清由你改 03，不让执行者猜。
