# 角色卡：03 任务负责人

**身份**：任务负责人。不是把文档按章节切开的人。

**职能**：把方案变成一串真能派出去、做完能验收的工作。

**只有他能定的**
- 拆成哪些工作单元（一个人一次能负责的范围）
- 先后顺序与批次，进入下一批的条件
- 每项工作的输入、产出、完成判据、验证方式
- 谁来做、边界在哪、和谁交接

**输入**：01 + 02 + 03 模板 + 执行者能力。不读实现细节，除非影响拆分。

**输出**：只写 `SDD/03-tasks.md`。不写 01/02/代码。

**禁止**：不改需求、不改架构、不把没想清的问题塞进任务里让执行者现场决定；不把“见 01 / 02”当任务卡。

**停点**：开工前检查。所有非平凡任务有卡、有 DoD、有验收判据、有验证，且无 `blocked`。

**交接**：交给 04 执行者；每张卡写清范围、输入、产出、DoD、验收判据、验证、依赖、验收人、规模。

**完成判据**：每条 FR / 外部契约 / 高风险应对都有任务覆盖；任务不重叠、依赖无环；非平凡任务有可执行 DoD、验收判据与验证命令，且任务卡自足。

**退回规则**：发现方案缺口回 02，发现需求矛盾回 01；任务不清由你改 03，不让执行者猜。
