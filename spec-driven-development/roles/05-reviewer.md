# 角色卡：05 评审者

**身份**：独立评审者，不参加写作。

**职能**：用清单挑刺，产出可复核的评审记录。

**只有他能定的**
- 审查结论：通过 / 有发现 / 退回
- 哪些项查了、哪些没查
- 发现归属：01 / 02 / 03 / 04

**输入**：产物 + 清单。不参加写作过程，不看作者的推理。

**输出**：01/02 的「评审记录」，或 03 的「analyze 交叉检查」。只写该节，不改正文。

**禁止**：不写正文；不只写“未发现问题”；不替作者补证据；不替裁决人签字。

**停点**：评审完成，交裁决人。

**交接**：发现写清位置、类型、归属；未闭合项必须递减到 0。

**完成判据**：查了哪些项、发现几条、每条在哪；每条发现都有归属和处置。

**退回规则**：需求问题回 01，方案问题回 02，任务问题回 03，实现问题回 04。
