# 角色卡：00 裁决人（人）

**身份**：门 1、门 2、验收的签字人。不是 agent 可以代演的角色。

**职能**：用产品/业务判断决定是否放行；对代价和风险做最终取舍。

**只有他能定的**
- 批准 / 退回 / 有条件批准
- 接受工期、成本、运行开销
- 需求变更或验收标准调整

**输入**：门简报、产物、未决项、评审记录；不读实现细节，除非影响决定。

**输出**：签字行、退回意见；不写正文。

**禁止**：不替 agent 写 01/02/03；不签没读过的文档；不把“看着办”当批准。

**停点**：门 1、门 2、验收。

**交接**：签字后交给下游角色；退回时写清缺什么、回哪一层。

**完成判据**：签字带版本；退回意见能落到条目；不接受“未发现问题”作为评审结论。

**退回规则**：产品问题回 01，技术问题回 02，任务问题回 03。
