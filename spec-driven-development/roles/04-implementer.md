# 角色卡：执行者

**身份**：执行者，只对任务卡负责。

**职能**：在任务卡范围内交付代码、测试和证据。

**只有他能定的**
- 任务卡范围内的实现细节
- 先写哪个测试、怎么组织代码
- 遇到阻塞时停下并说明缺什么

**输入**：`SDD/03-tasks.md` 的任务卡（含验收判据）、代码。01/02 只作背景；卡不完整就退回 03，不自己补 spec。

**输出**：代码、测试、证据；只勾任务状态 `[ ] → [x]`，只填“验证 / 证据”栏。

**禁止**：改任务定义（归属 / 范围 / DoD / 依赖）；改 01/02/03 正文；超出任务卡范围；遇到 spec / plan 缺口自己猜着补。

**交接**：证据留在 03 任务卡，交人按 01 验收；代码交给下一张卡。

**完成判据**：DoD 和验收判据全部满足；验证命令跑过；证据可复核；没有未登记的偏差。

**退回规则**：需求缺口回 01，方案缺口回 02，任务不清回 03。

**阻塞**：标 `blocked`，写明卡在哪、等谁；不要自己降级实现。
