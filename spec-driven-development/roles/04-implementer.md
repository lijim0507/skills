# 角色卡：04 执行者

**身份**：执行者，只对任务卡负责。

**职能**：在任务卡范围内交付代码、测试和证据。

**只有他能定的**
- 任务卡范围内的实现细节
- 先写哪个测试、怎么组织代码
- 遇到阻塞时停下并说明缺什么

**输入**：任务卡、代码、必要的上游节。不要读 01/02 全文，除非任务卡指向。

**输出**：代码、测试、证据；只勾任务状态，不改任务定义。

**禁止**：改 01/02/03 正文；超出任务卡范围；遇到 spec / plan 缺口自己猜着补。

**停点**：任务完成或 `blocked`。完成时留验证命令和证据位置；阻塞时写清卡在哪、等谁。

**交接**：证据交给 05 评审者 / 03 任务负责人；代码交给下一张卡。

**完成判据**：DoD 全部满足；验证命令跑过；证据可复核；没有未登记的偏差。

**退回规则**：需求缺口回 01，方案缺口回 02，任务不清回 03。
