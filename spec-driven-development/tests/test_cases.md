# 测试用例

## 用例 1：完整规格通过

- 输入：包含全部六个章节、验收标准为列表的 spec.md
- 期望：脚本输出 `规格校验通过`，退出码 0

## 用例 2：缺少章节

- 输入：缺少「非目标」章节的 spec.md
- 期望：脚本以非零退出码结束，提示 `错误：缺少必需章节「非目标」`

## 用例 3：验收标准不可核对

- 输入：「验收标准」章节只有一段文字、没有列表条目
- 期望：脚本以非零退出码结束，提示缺少逐条列出的可核对条目

## 用例 4：文件不存在

- 输入：`check_spec.py not-exist.md`
- 期望：脚本以非零退出码结束，提示 `错误：规格文件不存在`

## 用例 5：空文件

- 输入：空的 spec.md
- 期望：脚本以非零退出码结束，提示 `错误：规格文件为空`
