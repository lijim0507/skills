## 摘要

单进程 Python CLI：CommandParser 解析并分发，TaskStore 读写 JSON 文件，TaskRenderer 输出。写入用临时文件 + 原子替换，失败不破坏原文件。三条 FR 都能用标准库兑现，无需外部服务。

关键取舍（详情见 `02-plan-research.md`）：

- 用 JSON 文件而非 SQLite：数据量小、单文件可搬，代价是并发写要自己加锁。
- 写入用临时文件 + 原子替换：多一次落盘，换失败不损坏原文件。
- 单进程 + 文件锁：不做服务端，代价是多实例并发受限于本地锁。
