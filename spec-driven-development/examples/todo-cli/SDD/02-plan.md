# 02-plan.md —— Todo CLI 技术方案

## 方案总览

单进程 Python CLI，CommandParser 解析参数，TaskStore 负责 JSON 文件读写，TaskRenderer 负责输出。

## 需求可行性核对

| 需求 / 契约 | 可行性 | 依据 / 条件 | 若不可行 |
| --- | --- | --- | --- |
| FR-001 | 可行 | Python 标准库即可 | 无 |
| FR-002 | 可行 | Python 标准库即可 | 无 |
| CLI 命令契约 | 可行 | argparse 支持 | 无 |
| 数据格式契约 | 有条件 | 需要文件锁避免并发写坏 | 单用户场景可接受 |

## 技术上下文

| 项 | 内容 |
| --- | --- |
| 运行平台 / 运行时 | Python 3.10+ |
| 工具链 | 标准库、pytest |
| 相关既有模块 | 无 |
| 关键约束 | 离线、单文件数据 |

## 模块划分

| 层 / 分类 | 模块 | 职责 | 拥有或读写的表 | 依赖 | 写权限 |
| --- | --- | --- | --- | --- | --- |
| 接口 | CommandParser | 解析命令与参数 | 无 | TaskStore | 无 |
| 存储 | TaskStore | 读写待办 JSON 文件 | todos.json | 无 | 唯一写权限 |
| 输出 | TaskRenderer | 格式化列表输出 | 无 | TaskStore | 无 |
