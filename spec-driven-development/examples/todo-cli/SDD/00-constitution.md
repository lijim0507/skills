# 00-constitution.md —— Todo CLI 项目宪法

## 核心原则

### C-01 本地优先

数据保存在本地，不依赖网络服务；离线可用。

- **可判定**：断网时 add / list 仍能成功。
- **出处**：示例需求“离线可用”。

### C-02 写入不破坏原数据

任何写操作失败都不能破坏已有待办。

- **可判定**：模拟写入失败后，原文件仍可被 list 读取。
- **出处**：示例需求“数据文件损坏时保留原文件”。

## 原则冲突

- 无。

## 治理

- 修订需记：版本号 / 批准日期 / 修订理由
- 本宪法优先于其他习惯做法
- 违反宪法的方案，必须在 `02-plan.md` 的复杂度跟踪里说明为什么值得破例；**破例由裁决人批准并记录日期**
- 破例只对本次方案有效，不自动成为新原则
