## 模块清单

| 模块 | 一句话职责 | 依赖（调用方向） |
| --- | --- | --- |
| CommandParser | 解析命令并分发 | TaskStore、TaskRenderer |
| TaskStore | 读写待办 | 无 |
| TaskRenderer | 格式化输出 | TaskStore |

## 模块契约与数据

### CommandParser

**公开变量**

#### Command

| 字段 | 类型 | 取值域 / 约束 | 说明 |
| --- | --- | --- | --- |
| action | str | add / list | 命令动作 |
| text | str | 可为空；不设固定长度上限 | add 的待办内容 |

**私有变量**

无。

**公开接口**

| 接口 | 功能 | 输入 | 输出 / 返回 | 错误 | 调用上下文 |
| --- | --- | --- | --- | --- | --- |
| `parse_args(argv: list[str]) -> Command` | 把 argv 解析成 Command | 命令行参数 | Command | E002 参数错误——打印用法，不执行 | 同步 |
| `execute(cmd: Command) -> int` | 分发命令并返回退出码 | 已解析命令 | 0 成功 | E001 数据文件损坏——报错并保留原文件；E002 参数错误——打印用法，不执行 | 同步 |

**模块约束**

- 只做解析与分发，不直接读写 `todos.json`。
- `Command.text` 是普通字符串，不设固定长度上限。
- 契约测试：`tests/test_parser.py`

### TaskStore

**公开变量**

#### Todo

| 字段 | 类型 | 取值域 / 约束 | 说明 |
| --- | --- | --- | --- |
| id | int | 从 1 递增，唯一 | 待办标识 |
| text | str | 非空，无固定长度上限 | 待办内容 |
| created_at | str | ISO 8601 | 创建时间 |

**私有变量**

#### todos.json

| 字段 | 类型 | 取值域 / 约束 | 说明 |
| --- | --- | --- | --- |
| todos | Todo[] | 可为空数组 | 全部待办，按创建顺序 |

**公开接口**

| 接口 | 功能 | 输入 | 输出 / 返回 | 错误 | 调用上下文 |
| --- | --- | --- | --- | --- | --- |
| `add(text: str) -> int` | 追加一条待办并返回退出码 | 待办文本 | 0 成功 | E001 数据文件损坏——报错并保留原文件；E002 参数错误——打印用法，不执行 | 同步 |
| `list_todos() -> list[Todo]` | 按创建顺序返回全部待办 | 无 | 待办列表 | E001 数据文件损坏——报错并保留原文件 | 同步 |

**模块约束**

- 是 `todos.json` 的唯一写者。
- 写入使用临时文件 + 原子替换；失败保留原文件。
- 返回的 `Todo` 是拷贝，调用方不持有文件句柄。
- 契约测试：`tests/test_store.py`

### TaskRenderer

**公开变量**

无。

**私有变量**

无。

**公开接口**

| 接口 | 功能 | 输入 | 输出 / 返回 | 错误 | 调用上下文 |
| --- | --- | --- | --- | --- | --- |
| `render(items: list[Todo]) -> None` | 把待办列表格式化到 stdout | 待办列表 | 无 | 无 | 同步；只读列表 |

**模块约束**

- 只读 `Todo` 列表，不读写存储。
- 输出格式由本模块决定，调用方不解析文本。
- 契约测试：`tests/test_renderer.py`

## 数据质量

- 创建 / 更新 / 删除 / 归档规则：本轮只创建和读取，不删除。
- 保留期 / 隐私 / 合规：本地文件，无服务端。
- 迁移 / 回填 / 兼容：v1 无迁移；读取时兼容缺失字段。
- 唯一性、幂等、并发控制：id 自增；单进程 + 文件锁。
