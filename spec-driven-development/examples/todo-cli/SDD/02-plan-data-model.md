## 生命周期与数据质量

- 创建 / 更新 / 删除 / 归档规则：本轮只创建和读取，不删除。
- 保留期 / 隐私 / 合规：本地文件，无服务端。
- 迁移 / 回填 / 兼容：v1 无迁移；读取时兼容缺失字段。
- 唯一性、幂等、并发控制：id 自增；单进程 + 文件锁。
