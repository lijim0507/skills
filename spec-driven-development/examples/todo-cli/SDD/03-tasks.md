### T001 实现 TaskStore 的 JSON 读写

- 归属：FR-001, FR-002
- 批次：B1
- 执行者：示例执行者
- 验收人：示例用户
- 目标：提供可测试的读写接口
- 范围：`src/todo/store.py`；不改 CLI 参数
- 输入：todos.json 路径
- 产出：TaskStore 类与单元测试
- 完成判据（DoD）：空文件、正常文件、损坏文件三种情况都有测试
- 验收判据：FR-001 损坏文件时 add 返回非 0 且原文件不变；FR-002 空列表 list 输出“No todos”且退出码 0。
- 验证：pytest tests/test_store.py
- 证据：pytest 输出（示例中省略）
- 依赖：无
- 可并行：否
- 规模：M
- 风险 / 回滚：写坏原文件；使用临时文件 + 原子替换

### T002 实现 add 命令

- 归属：FR-001, EC-01
- 批次：B2
- 执行者：示例执行者
- 验收人：示例用户
- 目标：`todo add <text>` 追加一条待办
- 范围：`src/todo/cli.py`；不改存储格式
- 输入：命令行参数
- 产出：add 子命令与测试
- 完成判据（DoD）：成功退出码 0，空参数退出码非 0
- 验收判据：Given 空列表，When add “买牛奶”，Then 退出码 0 且 list 包含；Given 空文本，Then 退出码非 0；Given 损坏文件，Then 非 0 且原文件不变。
- 验证：pytest tests/test_cli.py::test_add
- 证据：pytest 输出（示例中省略）
- 依赖：T001
- 可并行：是
- 规模：S
- 风险 / 回滚：参数解析错误；回退到 argparse 默认行为

### T003 实现 list 命令

- 归属：FR-002, EC-02
- 批次：B2
- 执行者：示例执行者
- 验收人：示例用户
- 目标：`todo list` 按创建顺序输出
- 范围：`src/todo/cli.py`、`src/todo/renderer.py`；不改存储
- 输入：todos.json
- 产出：list 子命令与测试
- 完成判据（DoD）：空列表输出 No todos；两条记录按顺序输出
- 验收判据：Given 两条待办，When list，Then 按创建顺序输出；Given 空列表，Then 输出“No todos”，退出码 0。
- 验证：pytest tests/test_cli.py::test_list
- 证据：pytest 输出（示例中省略）
- 依赖：T001
- 可并行：是
- 规模：S
- 风险 / 回滚：输出格式不稳定；用快照测试固定
