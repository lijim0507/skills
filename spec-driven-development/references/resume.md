# 断点恢复

新会话只凭 `SDD/` 文件恢复，不靠聊天记忆。

## 开工前检查

1. 读 `SDD/` 文件清单，确认缺件。
2. 读对应角色的角色卡与模板，写角色调用头。
3. 读上游产物的最新版本，不读聊天记录。
4. 复述三句：拿到了什么、要做什么、还缺什么。
5. 复述不出来，退回上游；不猜补。

## 角色切换

- 换角色 = 换上下文：只读上游产物，不读上一角色的推理过程。
- 同一会话无法隔离时，用新会话或新 sub-agent。
- 切换后先写角色调用头，再复述三句。

## 未决项
