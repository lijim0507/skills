## 角色选择与调用头

用户只选角色，后面直接说需求；AI 根据角色卡推断阶段、停点、只读和只写。写不完整就停：

```text
本次角色：<00-06 + 名称>
本次阶段：<S0-S9>
只读：<上游产物 + 角色卡 + 模板>
只写：<本阶段允许写的文件>
停点：<门 / 评审 / 任务完成>
禁止：<不能写什么、不能做什么>
```

## 角色边界检查

每个门、每次交接回答四句：

1. 我写了不属于我的文档吗？
2. 我做了不属于我的决定吗？
3. 我读了不该读的内容吗？
4. 我把上游缺口在下游私了吗？

任何一句“是”，先停，按角色卡退回规则处理。

## 角色切换

- 换角色 = 换上下文：只读上游产物，不读上一角色的推理过程。
- 同一会话无法隔离时，用新会话或新 sub-agent。
- 切换后先复述三句：拿到了什么、要做什么、还缺什么。
