# 门禁、简报与签字

## 门简报（每个门先给这一页）

- **要你拍板的决定**：3–5 条，按影响排序
- **代价 / 风险**：工期、成本、运行开销、不可逆点
- **未决项**：是否阻塞，阻塞谁
- **建议**：approve / reject / 退回哪一层

完整清单是附录，不要求裁决人逐条勾。裁决人只看简报和产物做决定。

## 门 1（01 之后）

完整勾选清单见 templates/01-spec.md 的「门 1」节；本文件只写门简报、签字、角色边界和写权限。

## 门 2（02 之后）

完整勾选清单见 templates/02-plan.md 的「门 2」节；本文件只写门简报、签字、角色边界和写权限。

## 角色边界检查（每个门）

1. 我写了不属于我的文档吗？
2. 我做了不属于我的决定吗？
3. 我读了不该读的内容吗？
4. 我把上游缺口在下游私了吗？

## 签字

```text
approve ｜ 裁决人：<名字> ｜ 日期：YYYY-MM-DD ｜ 版本：rN
```

未表态写 `待审`。正文一改，旧签字作废，回到 `待审`。

## 写权限

- 门结论只由裁决人写，agent 不代签。
- 评审者只写评审记录，不写正文。
- 02 / 03 / 04 接手先复述；复述不出来就退回。
- `analyze` 只写自己那一节。
- `converge` 只追加任务，不改正文。
- 上游未定的事项回上游，不在下游私了。

## 停机动作

- 到门即停，不在同一步继续写下游或代码。
- 未批准不得开工；“你看着办”仍按待审处理。
