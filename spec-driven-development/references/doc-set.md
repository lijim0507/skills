## 归属规则

- 对外承诺归 01，实现方式归 02，怎么拆 / 谁做 / 按什么顺序归 03。
- 每份文档只有一个作者角色；评审者只写评审记录，不写正文。
- 同一事实只写一处：外部契约在 01，内部契约在 02-contracts，任务判据在 03。

## 交接摘要

每份文档末尾写「交接给下一角色」，只写 diff 里看不出来的判断：边界、取舍、待确认项。

## 轻量模式映射

00 并入 README 的“项目宪法”节；02 子件并入 02-plan 对应节；04 只写验收记录。
